# חופשת משפחת אשכנזי 🌲 | היער השחור, אלזס ושווייץ 2026

אפליקציית PWA (Progressive Web App) מותאמת מובייל ודסקטופ לניהול וליווי החופשה המשפחתית.

## תכונות האפליקציה

1. **יועץ אישי מבוסס Gemini AI (3.8 Flash)**:
   - מתוכנן עם כל הדגשים של המשפחה: מורן (ללא כוסברה), אלה (צמחונית), יעל (שופינג ב-SEPHORA ו-PRIMARK), נבו (אטרקציות וטכנולוגיה), אביב ומורן (לוגיסטיקה ורוגע).
   - תומך בזיכרון שיחה מרובת שלבים והצעות מהירות (תוכנית ליום גשם, סופרים פתוחים, פארק אירופה ועוד).
2. **מפה אינטראקטיבית עם סינון קטגוריות**:
   - 33 נקודות עניין מסווגות: אטרקציות וטבע, מסעדות, סופרמרקטים, לינה ותחבורה.
   - קישורי ניווט ישירים בלחיצה אחת ל-**Waze** ול-**Google Maps**.
3. **רשימת יעדים וחיפוש**:
   - כרטיסי מידע מפורטים עם חיפוש חופשי וסינון לפי קטגוריה.
4. **כרטיסי מסעדה למלצר עם השמעה קולית (גרמנית וצרפתית)**:
   - הודעה מפורטת למלצר על צמחונות ואיסור כוסברה מוחלט.
   - כפתור השמעה קולית (Text-to-Speech) בגרמנית ובצרפתית עבור המלצר.
5. **תמיכת PWA מלאה ואופליין**:
   - Service Worker (`sw.js`) שומר את כל המפות, המקומות והכרטיסים בזיכרון המכשיר.
   - אפשרות להתקנה מלאה במסך הבית של הסמארטפון (iOS ו-Android).

## הרצה מקומית

1. פתחו טרמינל בתיקיית הפרויקט:
   ```bash
   cd "c:\Users\aviv2\Google Antigravity\Projects\black-forest-trip"
   ```
2. הריצו:
   ```bash
   npm run dev
   ```
3. פתחו בדפדפן: `http://localhost:5173`

## התקנה על הסמארטפון

- **במכשירי Android (Chrome)**: לוחצים על שלוש הנקודות למעלה ובחורים ב-"התקן אפליקציה" (או לוחצים על כפתור ההתקנה באפליקציה).
- **במכשירי iPhone (Safari)**: לוחצים על כפתור השיתוף (הריבוע עם החץ למעלה) ובוחרים ב-"הוסף למסך הבית" (Add to Home Screen).
